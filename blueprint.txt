1. Tujuan Aplikasi

Aplikasi ini berfungsi sebagai:

Monitoring perangkat IoT mesin jahit

Mencatat IoT rusak

Mencatat instalasi baru

Mempermudah teknisi mencari device bermasalah

Bisa dipakai di HP & Web Browser

2. Teknologi Stack
Frontend

Next.js (App Router)

Tailwind CSS → UI cepat dan ringan

Shadcn UI / Radix UI → komponen profesional

PWA Support → install ke HP seperti aplikasi native

ZXing / html5-qrcode → barcode scanning

Backend / Database

Firebase Authentication → login user

Firestore → database realtime

Firebase Storage → upload CSV & foto device

Firebase Functions → logic import CSV, validasi data

Optional Tambahan (Sangat Direkomendasikan)

Sentry → error tracking

Zustand / Redux Toolkit → state management

React Query / Tanstack Query → caching data

Cloud Scheduler → backup otomatis
